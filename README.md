About the Project

This project analyzes 1,230 PM-JAY empanelled hospital records across 51 districts of Madhya Pradesh.

The analysis focuses on:

* District-wise hospital distribution
* Hospital type distribution
* Specialty availability
* Frequently reported specialty codes
* Statistical and correlation analysis
* Comparison of hospital types across districts

Dataset

The project uses the original hospital dataset provided for the analysis.

* Original Dataset: Data sets of data analytics.xls
* Cleaned Dataset: ayushman mp hospitals clean.csv

1. Open the notebook ayushman_bharat_analysis.ipynb in Google Colab.
2. Upload the original Excel dataset to the Colab session.
3. Rename the uploaded dataset to Data_sets_of_data_analytics.xls if required by the notebook.
4. Run the notebook cells in order.

Key Findings

* A total of 1,230 hospitals are distributed across 51 districts.
* Bhopal has the highest number of empanelled hospitals, with 256.
* The top three districts are Bhopal, Indore and Jabalpur.
* Private (For Profit) hospitals account for approximately 49.7% of the records.
* The average number of specialties per hospital is approximately 5.67.
* The correlation between total hospitals and average specialties across districts is approximately 0.357.

Conclusion

The analysis highlights differences in hospital distribution, hospital types and specialty availability across Madhya Pradesh districts. It provides a descriptive overview of the PM-JAY empanelled hospital network.
