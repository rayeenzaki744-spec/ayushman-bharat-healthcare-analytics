## About
Analysis of 1,230 PM-JAY empanelled hospital records across 51 districts of Madhya Pradesh: hospital distribution by district, hospital type and specialty, and districts with low coverage.

## Files
- Data sets of data analytics.xls: original dataset (PM-JAY Hospital Search Portal)
- ayushman mp hospitals clean.csv: cleaned dataset
- ayushman bharat analysis.ipynb: Jupyter Notebook (cleaning, EDA, charts, statistics)
- PBL Report Ayushman Bharat Healthcare Analytics.docx: PBL report
- fig1 to fig4 png files: charts

## How to run
1. pip install pandas numpy matplotlib xlrd jupyter
2. Keep the dataset in the same folder as the notebook. The notebook reads the file named Data_sets_of_data_analytics.xls, so rename the dataset file to that name.
3. Open the notebook and Run All.

## Key findings
- Bhopal has 256 hospitals (20.8%); the top 3 districts hold 38.4%.
- Private (For Profit) hospitals are 49.7% overall; public hospitals dominate smaller districts like Rewa.
- 14 districts have 9 or fewer hospitals.

AI tool used: Claude (Anthropic), for report drafting and analysis code.
